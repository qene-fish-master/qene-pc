青魚電腦 Qene Fish PC（QeneOS）
================================
主要功能
- 桌面：視窗拖曳/縮放/貼齊/最小化/最大化、虛擬桌面、工作列、開始功能表、快速設定、通知與行事曆、右鍵選單、鎖定/登入/睡眠/關機/重新啟動
- 應用程式：檔案總管（資源回收筒、複製貼上、拖放、匯入/下載真實檔案）、記事本、小算盤、行事曆、小畫家、終端機、工作管理員、相片、媒體播放器、相機、瀏覽器、青魚遊戲、設定、Qene 商店
- 商店可安裝：時鐘（世界時鐘/鬧鐘/計時器/碼表）、魚缸、手機連結（電話/訊息）、便利貼、錄音機
- 滑鼠：游標樣式/大小/顏色、軌跡、點擊波紋、Ctrl 定位、搖動放大、打字時隱藏、雙擊速度
- 系統：開機/安裝畫面、首次設定（OOBE）、系統更新（可重新啟動安裝，重新開機後續跑）、重設此電腦
- 資料存在瀏覽器（IndexedDB / localStorage），舊版「青魚手機」的設定與筆記會自動搬移。

這是網頁模擬器，不是真正的作業系統。
